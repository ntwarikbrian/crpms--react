# Car Repair Payment Management System (CRPMS)

A full-stack application designed to manage car repair services, payments, and reporting.

## Project Structure

The project is divided into two main parts:

- **FRONT**: The frontend application built with React, Vite, and Tailwind CSS.
- **BACK**: The backend API built with Node.js, Express, and MySQL.

## Getting Started

### Prerequisites

- Node.js installed
- MySQL database

### Backend Setup

1. Navigate to the `BACK` directory:
   ```bash
   cd BACK
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Configure your environment variables in a `.env` file (refer to the project documentation for required fields).
4. Start the development server:
   ```bash
   npm run dev
   ```

### Frontend Setup

1. Navigate to the `FRONT` directory:
   ```bash
   cd FRONT
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Technologies Used

- **Frontend**: React, Vite, Tailwind CSS, Axios, React Router
- **Backend**: Node.js, Express, MySQL, JSON Web Tokens (JWT), BcryptJS
- **Database**: MySQL
